# bezaitis.com

My personal site: plain HTML and CSS, generated by one Python script, hosted on GitHub Pages.

## Editing

All text, trips and projects live in `content/site.json`. After changing it, rebuild:

```
python3 build.py
```

That rewrites every `index.html`. Commit the result and push.

## Adding a trip

1. Put the photos in `assets/img/<slug>/` as `01.webp`, `02.webp`, … plus a smaller `01-sm.webp`, `02-sm.webp`, … (about 720px on the long edge). `01` is the cover.
2. Add an entry to `trips` in `content/site.json`:
   ```json
   {"slug": "iceland", "title": "Iceland", "date": "2026-08", "countries": ["352"], "pin": null,
    "text": ["One paragraph about the trip."], "photos": ["01.webp", "02.webp"]}
   ```
   `countries` uses ISO 3166 numeric codes (three digits). `pin` is `[longitude, latitude]` for a city trip, or `null`. A new country also needs its name in `COUNTRY_NAMES` in `build.py`.
3. Run `python3 build.py`.

To convert phone photos to WebP: `cwebp -q 72 -resize 1600 0 photo.jpg -o 01.webp` (use `-resize 0 1600` for portrait photos).

## Layout

- `build.py`: page templates and the build
- `assets/css/site.css`: the one stylesheet
- `assets/js/atlas.js`: the travel map; `assets/js/gallery.js`: the photo viewer
- `assets/vendor/`, `assets/data/`: d3-geo, topojson and the world atlas, stored here so the site has no outside dependencies besides Google Fonts
